## Directory Layout

```
[project-root]/
├── composeApp/                 # Main Kotlin Multiplatform module
│   └── src/
│       ├── commonMain/         # Shared code for all platforms
│       │   └── kotlin/de/fampopprol/dhbwhorb/
│       │       ├── data/       # Data sources (Remote, Storage)
│       │       ├── services/   # Business logic / Orchestration
│       │       ├── ui/         # Screens, ViewModels, Components
│       │       └── util/       # Shared helpers
│       ├── androidMain/        # Android-specific implementations
│       ├── desktopMain/        # Desktop-specific implementations
│       ├── iosMain/            # iOS-specific implementations
│       └── macosMain/          # macOS-specific implementations
├── iosApp/                     # iOS Native Project (Xcode)
├── macosApp/                   # macOS Native Project (Xcode)
├── documentation/              # Project documentation
├── fastlane/                   # CI/CD Automation scripts
├── gradle/                     # Gradle configuration and wrappers
├── metadata/                   # App metadata for stores (F-Droid)
└── packaging/                  # Platform-specific installers (Windows)
```

## Directory Purposes

**composeApp/src/commonMain:**
- Purpose: The core of the application. Contains all UI logic (Compose Multiplatform) and business rules.
- Contains: Business logic, Data models, UI components, ViewModels, and platform-independent services.
- Key files: `App.kt` (Main Entry/DI).

**composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data:**
- Purpose: All data-related code.
- Contains: `dualis/` (API and HTML parsing), `storage/` (Room database, preferences, credentials).

**composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/ui:**
- Purpose: UI components and screen-specific logic.
- Contains: `pages/` (Whole screens), `viewModels/`, `components/` (Reusable widgets), `theme/`.

**composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/services:**
- Purpose: Application-wide services that bridge the data and UI layers.
- Contains: `notifications/`, `widget/`, `LectureService.kt`.

## Key File Locations

**Entry Points:**
- `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/App.kt`: Root Composable and dependency injection hub.
- `composeApp/src/androidMain/kotlin/de/fampopprol/dhbwhorb/MainActivity.kt`: Android entry point.

**Configuration:**
- `build.gradle.kts`: Project-level build script.
- `composeApp/build.gradle.kts`: KMP module configuration.
- `gradle/libs.versions.toml`: Dependency version management.

**Core Logic:**
- `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/dualis/remote/DualisApiClient.kt`: Base network client.
- `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/storage/database/AppDatabase.kt`: Room database definition.

**Testing:**
- `composeApp/src/commonTest/kotlin/`: Shared unit tests.

## Naming Conventions

**Files:**
- PascalCase: `GradesViewModel.kt`, `DualisApiClient.kt`.

**Directories:**
- camelCase: `commonMain`, `androidMain`, `dualis`, `viewModels`.

## Where to Add New Code

**New Feature:**
- Primary UI: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/ui/pages/`
- ViewModel: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/ui/[feature]/viewModels/`
- Service: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/services/`
- Tests: `composeApp/src/commonTest/kotlin/`

**New API Endpoint:**
- Parser Logic: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/dualis/remote/parser/`
- Service Integration: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/dualis/remote/services/`

**New Database Entity:**
- Entity: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/storage/database/entities/`
- DAO: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/storage/database/dao/`
- Database update: `composeApp/src/commonMain/kotlin/de/fampopprol/dhbwhorb/data/storage/database/AppDatabase.kt`
