## Technical Notes

### Platform-Specific Implementations

**iOS (UIKit):**
- `openFile()`: Uses `UIDocumentInteractionController` with delegate pattern
- `saveFileWithDialog()`: Uses `UIActivityViewController` for sharing options
- Temp files stored in NSTemporaryDirectory

**macOS (AppKit):**
- `openFile()`: Uses `NSWorkspace.sharedWorkspace.openURL()`
- `saveFileWithDialog()`: Uses `NSSavePanel` for native save dialog
- Temp files stored in NSTemporaryDirectory

**Why Different Approaches?**
- iOS uses `UIActivityViewController` because `NSSavePanel` is macOS-only
- macOS uses `NSWorkspace` for direct file opening (not available on iOS)
- Both platforms supported through proper expect/actual pattern

### Kotlin Native Interop

- Uses `@OptIn(ExperimentalForeignApi::class)` for `kotlinx.cinterop` features
- Uses `usePinned` + `addressOf` for safe ByteArray-to-NSData conversion
- Uses proper platform frameworks: `platform.UIKit.*`, `platform.AppKit.*`, `platform.Foundation.*`
