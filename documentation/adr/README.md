# Architecture Decision Records

Eine Entscheidung pro Datei, nummeriert, nie umnummeriert. Eine überholte Entscheidung wird nicht
gelöscht, sondern bekommt den Status *Ersetzt durch ADR-XXXX*.

Status: `Vorgeschlagen` → `Angenommen` | `Abgelehnt` → später ggf. `Ersetzt`.

| Nr. | Titel | Status |
|---|---|---|
| [0001](0001-app-badge-ungesehene-aenderungen.md) | App-Badge zählt ungesehene Änderungen und wird beim Öffnen zurückgesetzt | Angenommen |
| [0002](0002-akzentfarbe-auf-apple-plattformen.md) | Wählbare Akzentfarbe auf iOS und macOS | Angenommen |
